# Mitigation Crisis – Survive-ID 🇮🇩

**Mitigation Crisis** adalah aplikasi web berbasis PWA (Progressive Web App) yang membantu pengguna menyusun **rencana mitigasi krisis dan survival** berdasarkan kondisi nyata di Indonesia.

Aplikasi ini dirancang untuk skenario darurat seperti:
- Gangguan pangan
- Krisis air
- Pemadaman listrik
- Gangguan komunikasi & internet
- Tekanan ekonomi mikro
- Kondisi darurat jangka pendek hingga menengah

---

## 🎯 Tujuan
Memberikan panduan **taktis, praktis, dan kontekstual** agar masyarakat dapat:
- Mengurangi risiko saat krisis
- Mengambil keputusan berbasis kondisi pribadi
- Meningkatkan kesiapan survival secara mandiri

Aplikasi ini **bukan pengganti instruksi resmi pemerintah atau tenaga profesional**, melainkan alat bantu mitigasi awal.

---

## ⚙️ Fitur Utama
- 📊 Analisis berbasis input pengguna (lokasi, iklim, sosial ekonomi, skill, aset)
- ⏱️ Skenario waktu krisis (1 hari, 7 hari, 14 hari, 1 bulan)
- 🌱 Rekomendasi pangan, air, energi, dan strategi bertahan
- 📄 Hasil panduan dapat disimpan sebagai **PDF**
- 📱 Bisa diinstal seperti aplikasi Android (PWA)
- 🌐 Dapat berjalan **offline**

---

## 🧠 Cara Kerja Singkat
1. Pengguna memilih jenis krisis
2. Menentukan durasi dan lingkungan
3. Mengisi profil sosial ekonomi dan aset
4. Sistem menghasilkan rencana mitigasi yang disesuaikan

Semua proses berjalan **di sisi klien (client-side)** tanpa mengirim data ke server.

---

## 🔐 Privasi & Keamanan
- Tidak memerlukan login
- Tidak mengumpulkan data pribadi
- Tidak menggunakan backend atau database
- Semua data diproses secara lokal di perangkat pengguna

---

## 🧪 Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
- Progressive Web App (PWA)
- Service Worker untuk offline mode

---

## ⚠️ Disclaimer
Aplikasi ini menyediakan panduan mitigasi berbasis prinsip survival umum dan simulasi kondisi.  
**Bukan pengganti saran medis, keselamatan, atau instruksi resmi dari pihak berwenang** seperti BNPB, SAR, atau instansi pemerintah lainnya.

Gunakan dengan pertimbangan dan tanggung jawab pribadi.
